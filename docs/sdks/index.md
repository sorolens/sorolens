# SDKs

Every client is built against [`docs/openapi.yaml`](https://github.com/sorolens/sorolens/blob/main/docs/openapi.yaml).

| Language | Package | Install | Docs |
| --- | --- | --- | --- |
| Python | `sorolens` (PyPI) | `pip install sorolens` | [Python SDK](../sorolens-python-sdk/index.md) |
| TypeScript / JavaScript | `@sorolens/sdk` (npm) | `npm install @sorolens/sdk` | [README](https://github.com/sorolens/sorolens/blob/main/packages/typescript-sdk/README.md) |
| Rust | `sorolens-sdk` (crates.io) | `sorolens-sdk = "0.1"` in `Cargo.toml` | [README](https://github.com/sorolens/sorolens/blob/main/packages/rust-sdk/README.md) |
| Go | `github.com/sorolens/go-client` | generated into `packages/go-client` | [README](https://github.com/sorolens/sorolens/blob/main/packages/go-client/README.md) |
| JVM (Kotlin, Java) | `sorolens-jvm` | built from `packages/jvm-sdk` | [README](https://github.com/sorolens/sorolens/blob/main/packages/jvm-sdk/README.md) |

The Python SDK pages, including its API reference, are built from the SDK's own
`packages/python-sdk/docs`. The other SDKs are documented in their READMEs.
