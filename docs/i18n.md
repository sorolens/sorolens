# Web Localization

The web app currently ships English (`en`) and Spanish (`es`) messages in
`apps/web/lib/i18n.tsx`. Add new locale entries with the same message keys, then
add the locale to the `Locale` type's source catalog and the language selector.
Keep locale keys aligned across catalogs so TypeScript catches missing strings.

The app starts with English and UTC formatting on both server and client. Saved
language and timezone preferences are restored after hydration from
`localStorage`; date and number formatting should use the shared helpers in
`apps/web/lib/format.ts` or the `useLocale()` helpers so the timezone selection
is respected.
