Sorolens

One-click tracking for Soroban contract IDs found on Stellar Expert, Stellar Lab and stellar.org.

API key

Create one in the dashboard (Admin → API keys). A key with write:contracts lets the extension register contracts that are not indexed yet; read-only keys still work for status and watchlists. Stored on this device only (storage.local), never synced.

Identity

The watchlist endpoints key on this identity. To share a watchlist with the dashboard, copy sorolens_user_id from localStorage on the Sorolens web app. Leave empty to generate a new one.
