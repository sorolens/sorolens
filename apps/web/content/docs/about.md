# About Sorolens

Sorolens is indexed observability for Soroban smart contracts on Stellar. It
turns raw RPC data into searchable events, invocation resource usage, storage
TTL health and proactive on-chain watchdog monitoring.

## Open source

Sorolens is MIT licensed and developed in the open. Contributions are welcome;
start with the [contributing guide](https://github.com/sorolens/sorolens/blob/main/CONTRIBUTING.md)
and the [architecture overview](https://github.com/sorolens/sorolens/blob/main/ARCHITECTURE.md).
